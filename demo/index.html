核心問題

「這次我要把哪一部分 cognitive work 留給自己，下次才不需要同樣程度的幫助？」 一般的 agentic coding 流程是：不會 → Agent 做 → 能跑 → 下一題。這個 skill 把它改成：Agent 先縮小未知範圍 → 你建立 mental model → 一起實作 → 你驗證 → 留下可遷移的模型。

      這份紀錄怎麼產生的

      Agent 那一方：真實輸出

      用 Claude Code 的 subagent 載入 skills/jit-learning-loop/SKILL.md，在 demo/project/ 這個真實的 Python 專案裡工作：讀 code、建 virtualenv、寫測試、跑測試、改 code。每一輪回覆原封不動存成 transcript/NN-agent.md，指令輸出存在 transcript/artifacts/。

      使用者那一方：模擬的學習者

      使用者的回覆（transcript/NN-user.md）由 Claude 扮演一位「第一次碰 Redis lock 的後端工程師」撰寫，而且刻意帶了常見的誤解（例如「asyncio 是 single-thread，所以不會 race」），用來展示預測被實驗推翻時，skill 如何修正 mental model。

      情境與程式碼

      checkout 服務的程式碼來自 repo 的 evals/files/checkout/：一個 FastAPI endpoint，先檢查 order 狀態、再呼叫 payment provider（300–900ms），最後才寫回 paid，是典型的 check-then-act race。

      自己重跑

      • cd demo/project && uv venv && uv pip install -r requirements.txt
      • .venv/bin/python -m pytest tests
      • 本機預覽這個頁面：python3 -m http.server -d demo
